# Diagnostic Verification Probes and Code Patterns

> Sub-skill: [`wallet-and-key-management-attacks-key-generation-weakness`](SKILL.md) | Family: **Blockchain**

Probes for `wallet-and-key-management-attacks-key-generation-weakness`. Each group names the baseline it is compared against and the differential that counts. Run every probe twice; a one-off difference is not proof.

## Entropy reproducibility

Baseline: the key generated by the code under review. Probe: an attempt to regenerate it from the purported source. Differential: a reproducible key means the entropy is predictable.

```python
candidate = int(time.time() * 1000) % (2**32)
print(candidate, hex(candidate))
```

## Nonce reuse test

Baseline: `r` from signature one. Probe: `r` from signature two over a different message. Differential: equal `r` values mean the nonce repeated and the key is derivable.

```python
sig1 = sk.sign_deterministic(b'a', hashfunc=hashlib.sha256)
sig2 = sk.sign_deterministic(b'b', hashfunc=hashlib.sha256)
print(sig1[:32].hex(), sig2[:32].hex(), sig1[:32] == sig2[:32])
```

## Usage Rules

- Baseline first, probe second, same scope and same credentials for both runs.
- Stop at the first confirmed differential; do not expand the probe once it fires.
- Pair every confirmed finding with the structural remediation in [`SKILL.md`](SKILL.md).
